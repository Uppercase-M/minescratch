## Overview
Minescratch is an attempt to recreate the famous sandbox game in Turbowarp (Scratch mod) using several extensions such as ***Simple3D*** or ***Pointerlock***. The current project is mostly empty and laking almost all the features from the base game. But it will not stay like this as I plan to add more features on the long term.

## Installation
Just download the *.sb3* file and run it. It isn't packaged as i want people to be able to play with it and modify as they wish.
OR
Run the HTML file directly. Safe. More stable (I think)

## Playability
### Controls :
- <kbd>Z</kbd> - Move forward
- <kbd>S</kbd> - Move backward
- <kbd>Q</kbd> - Strafe left
- <kbd>D</kbd> - Strafe right
- <kbd>Space</kbd> - Jump
- <kbd>U</kbd> - Debug menu (Similar to F3 menu in Minecraft)
- <kbd>Escape</kbd> - Unlock mouse (Unstable)
